### Hi, I'm Yifan Wang 👋

I build **evidence-grounded LLM agent systems**, because trusting a model on vibes alone is how you end up debugging at 3am.

I'm a grad student at Sichuan University's School of Computer Science. My job: give agents instructions, then rigorously check whether they actually followed them.

---

### 🔬 What I'm working on

- **Evidence-grounded agent harnesses** — the LLM makes the decisions, a deterministic Python runtime keeps the receipts. Every tool call, approval, and checkpoint has a paper trail ([job-agent-harness](https://github.com/YiFanWangSCU/job-agent-harness)).
- **Post-training robustness** — what happens to an agent when its skill prompt goes missing? Short answer: chaos. Long answer: *measurable* chaos ([skill-annealing](https://github.com/YiFanWangSCU/skill-annealing)).
