### 🔬 What I'm working on

- **Evidence-grounded agent harnesses** — separating LLM semantic decisions from a deterministic Python runtime, so tool calls, approvals, checkpoints, and failures are observable and verifiable ([job-agent-harness](https://github.com/YiFanWangSCU/job-agent-harness)).
- **Post-training robustness** — a controlled study of how an agent's structured decisions change when its skill prompt is incomplete or missing ([skill-annealing](https://github.com/YiFanWangSCU/skill-annealing)).
